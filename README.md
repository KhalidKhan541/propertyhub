## ✨ Features

### Real Estate Modules (20+ pages)
- 📊 **Dashboard** — Brokerage overview with revenue, listings, deals
- 📈 **Analytics** — Revenue trends, property type breakdown
- 🏠 **Listings** — Property management with filters
- 📋 **Property Details** — Full property view with features
- 🎥 **Virtual Tours** — 3D tour management
- 📄 **Documents** — Transaction document management
- 🎯 **Leads** — Lead pipeline with scoring
- 🗓️ **Tours** — Tour scheduling and management
- 🤝 **Offers** — Offer tracking and negotiation
- 💰 **Transactions** — Deal management and tracking
- 👥 **Clients** — Client CRM
- 👨‍💼 **Agents** — Agent performance management
- 🏢 **Teams** — Team organization
- 🏘️ **Neighborhoods** — Market analysis by area
- 💵 **Commissions** — Commission tracking and splits
- 📢 **Campaigns** — Marketing campaign management
- 👥 **Team** — Role-based team management
- 🔑 **API** — RESTful API and MLS integration
- 💳 **Billing** — Subscription plans
- ⚙️ **Settings** — Brokerage configuration

### Platform Features
- 🌙 Dark / Light / System mode
- 🎨 White-label ready (CSS variable theming)
- 📱 Fully responsive
- ⚡ No database required (mock data)
- 🧩 Modular architecture

## 🚀 Getting Started

```bash
git clone https://github.com/KhalidKhan541/propertyhub.git
cd propertyhub
npm install
npm run dev
```
